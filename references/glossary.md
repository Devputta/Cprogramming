# C Programming Glossary

| Term | Meaning |
|---|---|
| Address | Location of an object in memory |
| Argument | Value supplied to a function call |
| Array | Contiguous sequence of same-type elements |
| Base case | Stopping condition in recursion |
| Block | Statements enclosed in braces |
| Cast | Explicit type conversion |
| Compiler | Translates source into lower-level representation |
| Constant | Value not intended to change |
| Declaration | Introduces an identifier and its type |
| Definition | Provides an entity's implementation or storage |
| Dereference | Access the object referred to by a pointer |
| Expression | Combination of operands and operators yielding a value |
| File pointer | `FILE *` stream handle |
| Function | Named reusable unit of program logic |
| Identifier | Name chosen by the programmer |
| Initialization | Giving an object its initial value |
| Iteration | Repetition using a loop |
| Linker | Combines object files and libraries |
| Loop | Control structure for repetition |
| Null character | `'\0'`, terminates a C string |
| Null pointer | Pointer that does not point to an object or function |
| Parameter | Variable declared in a function parameter list |
| Pointer | Object that stores an address |
| Prototype | Function declaration with parameter types |
| Recursion | Function calling itself |
| Scope | Region where an identifier can be used |
| String | Character sequence ending in `'\0'` |
| Structure | Aggregate type with named members |
| Undefined behavior | Behavior for which the C standard imposes no requirements |
| Union | Type whose members share storage |
| Variable | Named object whose stored value may change |
